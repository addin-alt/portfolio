# Al Addin — Professional Portfolio

A formal, compact, responsive, animation-rich static portfolio 

## What changed

- Smaller and more minimal typography
- Cleaner premium color palette
- Long scrolling professional structure
- All major information editable directly from `index.html`
- 20+ GitHub projects included, with the strongest projects prioritized
- Contact section with static form markup and email fallback
- Smooth reveal animation, scroll progress, sticky nav, filters, counters, and mobile menu
- Responsive layout for phone, tablet, laptop, and desktop
